# Diagnóstico y Fundamentos de Bases de Datos NoSQL - SENA CTMA

Repositorio con las evidencias y scripts de la Semana 1 para el caso de estudio de la **Unidad de Emprendimiento del SENA**.

## Contenido del Repositorio

- `p1_json.py`: Corrección y lectura de estructuras JSON.
- `p2_filtrar.py`: Script para filtrado de listas y diccionarios manejando campos ausentes.
- `p3_sql.py`: Consulta SQL relacional con JOIN en SQLite en memoria.
- `01_explorar.py`: Exploración de documentos BSON y verificación del tipo nativo Date/datetime para MongoDB.
- `01_explorar.js`: Script equivalente para MongoDB Shell (`mongosh`).

## Instrucciones de Ejecución

Asegúrate de tener Python 3 instalado y ejecuta cada script desde la terminal:

```bash
python p1_json.py
python p2_filtrar.py
python p3_sql.py
python 01_explorar.py
